关键实测结论

接缝链式续写段的接缝像素差 1.4–3.2，段内正常帧间差 12–16 → 衔接比普通帧间更平滑。

硬约束帧数 ≥33（17 帧必崩成彩色噪声）；续写段可用深度仅 20–86 帧且浮动； 241 帧全链最后约 0.5–1 秒会糊化 → 干净成片需按锐度曲线裁尾 + 重定时。

可用GGUF 底模可直接挂 LoRA（实测复现官方 Turbo 合并模型效果，锐度 −15%）。

解码4 步档下瓶颈转为 VAE 瓦片解码（~2.5 s/帧 @480p，~5 s/帧 @720p）。
