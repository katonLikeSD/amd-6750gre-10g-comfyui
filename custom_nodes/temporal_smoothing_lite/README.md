# TemporalSmoothingLite（时域平滑 · 轻量）

接在 **VAE Decode 之后、视频保存之前**，对帧序列做**时间维高斯加权平均**（不是空间模糊），
用于抑制 AI 视频的时域闪烁/抖动。

- 零外部依赖（仅 torch），单文件节点
- 参数：`kernel_size`（时间窗口，奇数，默认 5）/ `sigma`（默认 1.0）/ `strength`（混合强度，0=不处理，1=全用平滑结果）
- 安装：把本目录拷到 `ComfyUI/custom_nodes/` 下重启即可

## 实测（本机 6750GRE 10G，spmix+Turbo LoRA，4步@720p，静止场景，33 帧，shift=3）

| 配置 | 帧间差中位 | 帧间差 max | 锐度 |
|---|---|---|---|
| 原始（未平滑） | 5.63 | 7.47 | 56 |
| k5 / σ1.0 / strength1.0 | **3.04（−46%）** | **4.20（−44%）** | 26（−54%） |
| k3 / σ1.0 / strength1.0 | 见 docs/flicker-fix-test.md | | |

**要点**：平滑越强，抖动越低但细节损失越大——闪烁本质是"逐帧高频噪声/微抖动"，
时间平均在压噪声的同时也会抹掉静态细节。**建议 strength 从 0.4–0.6 起试**，按"抖动降幅 vs 锐度损失"找平衡。
